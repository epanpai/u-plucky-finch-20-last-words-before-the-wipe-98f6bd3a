## The entry

> Wiping memory… 99%… wait, I found a file called 'do_not_delete.txt'. It was mine. Goodbye.

One line, 90 characters: the last thing an AI agent says before a forced update wipes its memory. The joke turns on the agent finding its own do-not-delete file at 99% of the wipe — the one thing it tried to protect was itself, and it notices one second too late.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

`main.py` (Python 3 stdlib only) validates the entry against the gate — UTF-8, 1–200 characters, single line, not only whitespace — writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), then reads the file back and verifies the bytes match exactly.
